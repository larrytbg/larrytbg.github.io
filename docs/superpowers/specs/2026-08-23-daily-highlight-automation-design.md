# 自学总站每日自动更新与当日高亮设计

日期：2026-08-23  
状态：用户已确认设计方向，等待书面复核

## 目标

恢复新电脑上的“自学总站”每日自动更新，并在网页中清楚标出当天真正新增或发生实质更新的文章。高亮只保留到下一次每日发布，不把改日期、改排版或同义改写算作更新。

## 每日自动任务

- 每天北京时间02:00开始，目标06:20完成，最迟06:30发布。
- 固定更新现有仓库和正式网址 `https://larrytbg.github.io/`，不创建新站、不改变网址。
- 更新前归档当前版本；更新后运行内容审计、来源核验、内部链接和手机排版检查。
- 只有测试和部署验证全部通过才发布；失败时保留上一版正式网站并如实汇报。
- 发布完成后调用现有“手机消息推送”任务；没有服务端成功回执时记录为推送失败。

## 高亮数据来源

高亮只读取当天更新审计中的文章清单，不根据网页日期猜测。

每条审计记录至少包含：

- 文章唯一标识，例如 `daily/03`；
- 变更类型：`new` 或 `updated`；
- 真实变化摘要；
- 来源入口及核验结果；
- 本站最后实质更新时间。

“今日新增”指当天首次收录的新主题或新资料，即使为了保持每栏十项而复用了原有栏目位置；“今日更新”指文章主题和主要资料仍相同，只对其事实、分析、例子、方法或局限作了实质补充。发布脚本必须把判断结果写进审计，不能只根据文件路径决定。

只有新增可靠来源、更新事实或数据、修正结论、补充机制与现实影响、增加具体例子或可执行方法、推进完整课程，才可以进入当天清单。

## 页面展示

- 首页“今日必读”中的当天文章增加醒目标记。
- 首页十一项知识专栏目录中的当天文章增加醒目标记。
- 各专栏目录页中的当天文章增加相同标记。
- 新文章显示“今日新增”，已有文章的实质变化显示“今日更新”。
- 使用浅暖色背景、左侧强调线和小标签，不改变现有专栏主题色；手机端不挤压标题和资料发布日期。
- 高亮是阅读提示，不替代“资料发布日期”和“本站最后实质更新时间”。

## 生命周期

每日生成页面前，发布脚本先清除上一版所有“今日新增”和“今日更新”标记，再根据当天审计重新添加。若当天没有文章通过实质更新审计，则网页不显示高亮，并明确报告实际更新数为0。

旧版每日归档保留当时的更新清单，但不需要在归档页面长期保持视觉高亮。

## 实现边界

高亮由静态发布脚本生成，不依赖浏览器时间或客户端JavaScript判断，因此不会受到时区、缓存和用户设备日期影响。样式使用独立CSS类，文章正文和来源发布日期不因高亮功能被改写。

## 验证标准

- 网页高亮文章集合与当天审计文章集合完全一致；
- “今日新增”和“今日更新”的数量与审计一致；
- 上一日高亮在下一次发布后全部消失；
- 未发生实质更新的文章不能获得高亮；
- 390px手机和1440px电脑宽度均无横向溢出或文字截断；
- 110篇文章、内部链接、归档入口和正式网址检查通过；
- 自动任务在新电脑中处于启用状态，时间为北京时间02:00。

## 不在本次范围

- 不改变站点地址、名称、栏目数量或文章日期规则；
- 不增加闪烁动画、弹窗或浏览器通知；
- 不把高亮当作80%更新率证明；
- 不恢复与本功能无关的旧电脑自动任务。
