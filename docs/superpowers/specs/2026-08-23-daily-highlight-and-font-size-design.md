# 自学总站高亮颜色与字体放大设计

日期：2026-08-23

## 目标

把“今日新更新”的黄色高亮改成更柔和、辨识清楚的浅蓝色，同时整体提高正文、摘要和日期文字的可读性。页面结构、文章内容、日期规则和每日高亮判定规则均不改变。

## 已确认的视觉方案

### 今日新更新

- 背景采用浅蓝渐变，建议从 `#e8f3ff` 过渡到接近白色。
- 左侧提示线采用中等蓝色 `#3c78a8`。
- “今日新更新”徽标采用深蓝底、浅色字，保证在米白背景和首页深色区域都有足够对比度。
- 只改变真实新增或实质更新项目的视觉样式，不扩大高亮范围，也不恢复已清除的旧高亮。

### 字体放大

- 首页卡片摘要：从约 12px 提高到 14px。
- 专栏目录正文：从约 13px 提高到 15px。
- 专栏文章摘要：从约 15px 提高到 16px。
- 文章正文：从约 16px 提高到 17px。
- 日期及辅助文字：最低提高到 12px。
- 主要大标题保持现有尺寸，避免重新占用大量首屏空间。
- 行距只作小幅配套调整，保证放大后仍然紧凑、容易连续阅读。

## 实现边界

- 高亮颜色只修改 `site/assets/daily-highlights.css`。
- 字体调整集中写入全站共用样式，不逐页手工修改 194 个 HTML 页面。
- 不修改文章正文、文章日期、来源链接、高亮审计数据或自动化更新逻辑。
- 不新增动画、阴影装饰或其他无关视觉元素。

## 响应式要求

- 桌面端保持当前网格和卡片密度。
- 手机端仍保持单列布局，不产生横向滚动或文字截断。
- 手机端正文保持 17px；日期文字不得小于 12px。
- 徽标允许自然换行或缩短占用，但不能遮挡标题。

## 验收标准

1. 高亮项目显示浅蓝色背景和蓝色提示线，不再出现原黄色高亮。
2. 非高亮项目背景不发生变化。
3. 首页、专栏目录和文章详情页的正文、摘要及日期文字按上述幅度放大。
4. 大标题尺寸和页面结构保持不变。
5. 390px 手机宽度和桌面宽度下均无横向溢出。
6. 每日高亮判定测试、日期测试和内部链接测试继续通过。
7. 发布后公网首页及至少一个专栏页、文章页可访问并显示新样式。
