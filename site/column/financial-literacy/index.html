LEARNING PATH

由浅入深的学习框架

当前位置会随学习进度推进。先掌握本层，再进入下一层；已学内容仍可随时回看。

  1. 01

    初级一：财务语言

    当前阶段

    分清资产、负债、权益、收入、成本、费用和利润。

    实际应用：能用会计恒等式解释一笔交易。
  2. 02

    初级二：三张报表

    后续阶段

    知道资产负债表、利润表和现金流量表分别回答什么。

    实际应用：能把利润与现金差异说清楚。
  3. 03

    中级一：预算与成本

    后续阶段

    掌握预算差异、固定成本、变动成本和贡献毛利。

    实际应用：能分析超预算和盈亏平衡点。
  4. 04

    中级二：经营效率

    后续阶段

    理解库存、应收、应付和现金周转。

    实际应用：能发现资金被哪个经营环节占住。
  5. 05

    高级一：综合分析

    后续阶段

    把盈利、效率、杠杆和现金流放在一起判断。

    实际应用：能拆解ROE等指标背后的真实来源。
  6. 06

    高级二：财务决策

    后续阶段

    理解时间价值、折现率、净现值和资本结构。

    实际应用：能为长期项目建立多情景判断。
