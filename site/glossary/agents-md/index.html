Project Guidance File

一句话理解：保存在项目中的长期协作说明文件。

01

它到底是什么

它用于记录代码规范、常用命令、验证方式和交付要求，使后续任务进入项目时先获得稳定规则。

02

最简单的例子

网站项目可以在文件中写明构建命令、发布方式和不能触碰的目录。

03

最容易混淆的地方

这个概念有明确的使用条件，不能只看名称就直接套用；应同时检查文章中的对象、证据和边界。
